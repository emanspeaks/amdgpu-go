# amdgpu-go

Go bindings for the `libdrm_amdgpu` C library. Provides direct access to AMD GPU devices via DRM ioctls, with an amdgpu_top-compatible JSON output layer.

## Features

- Device open/close via `/dev/dri/renderD*`
- Device info (family, clocks, cache sizes, APU flag)
- Memory info (VRAM/GTT heap usage, resizable BAR detection)
- MMIO register reads (GRBM/GRBM2 performance counters)
- GRBM/GRBM2 bit tables for activity decoding
- Chip metadata (name, GFX target, generation) from family ID
- DRM driver version
- Firmware version queries
- Hardware IP block info
- amdgpu_top-compatible JSON frame builder

## Platform support

| Feature | Linux | Windows |
| --- | --- | --- |
| Device open/close | ✓ | stub (ErrWindowsBackend) |
| Device/memory info | ✓ | stub |
| MMIO register reads | ✓ | stub |
| GRBM bit tables | ✓ | ✓ |
| Chip metadata | ✓ | ✓ |
| Frame builder | ✓ | ✓ |
| Sensor reads | planned | stub |

## Build requirements

Linux requires CGO and the DRM development libraries:

```bash
# Debian/Ubuntu
sudo apt install libdrm-dev libdrm-amdgpu1

# Fedora
sudo dnf install libdrm-devel libdrm-amdgpu

# Arch
sudo pacman -S libdrm
```

Windows builds succeed without CGO (all device functions return `ErrWindowsBackend`).

### NixOS

Add `pkgs.libdrm` to `buildInputs` and `pkgs.pkg-config` to `nativeBuildInputs`. A minimal dev shell:

```nix
devShells.default = pkgs.mkShell {
  nativeBuildInputs = [ pkgs.pkg-config pkgs.go ];
  buildInputs = [ pkgs.libdrm ];
};
```

`pkgs.libdrm` provides both `libdrm.pc` and `libdrm_amdgpu.pc` from the same package — no separate `libdrm_amdgpu` derivation is needed. Set `CGO_ENABLED=1` explicitly if your shell or wrapper does not inherit it.

This package uses [gomod2nix](https://github.com/nix-community/gomod2nix) for reproducible Nix builds. The `gomod2nix.toml` file is auto-generated by CI whenever `go.mod` changes. Because this package has no external Go module dependencies, `go.sum` is never created; this is expected and not an error.

## Usage

```go
import "github.com/emanspeaks/amdgpu-go/amdgpu"
```

### Open a device

```go
dev, err := amdgpu.Open(0) // opens /dev/dri/renderD128
if err != nil {
    log.Fatal(err)
}
defer dev.Close()
```

### Device and chip info

```go
info, err := dev.DeviceInfo()
if err != nil {
    log.Fatal(err)
}

meta := amdgpu.ChipMetaForFamily(info.Family)
fmt.Printf("GPU:    %s (%s)\n", meta.Name, meta.GFXTarget)
fmt.Printf("Family: %s\n", meta.GPUFamily)
fmt.Printf("Engine: %d kHz max\n", info.MaxEngineClock)
fmt.Printf("Memory: %d kHz max\n", info.MaxMemoryClock)
fmt.Printf("APU:    %v\n", info.IsApu)
```

### Memory info

```go
mem, err := dev.MemoryInfo()
if err != nil {
    log.Fatal(err)
}

fmt.Printf("VRAM usage: %d MB / %d MB\n",
    mem.VRAMHeapUsage>>20, mem.VRAMTotalHeapSize>>20)
fmt.Printf("GTT usage:  %d MB / %d MB\n",
    mem.GTTHeapUsage>>20, mem.GTTTotalHeapSize>>20)
fmt.Printf("ReBAR:      %v\n", mem.ResizableBar)
```

### GRBM performance counters

```go
vals, err := dev.ReadMMRegisters(amdgpu.GRBMOFFSET, 1)
if err != nil {
    log.Fatal(err)
}

gen := amdgpu.DetectGeneration(info.Family)
for _, bit := range amdgpu.GRBMBits() {
    if vals[0]&(1<<bit.Bit) != 0 {
        fmt.Printf("  active: %s\n", bit.Name)
    }
}

vals2, _ := dev.ReadMMRegisters(amdgpu.GRBM2OFFSET, 1)
for _, bit := range amdgpu.GRBM2BitsForGen(gen) {
    if vals2[0]&(1<<bit.Bit) != 0 {
        fmt.Printf("  active: %s\n", bit.Name)
    }
}
```

### DRM driver version

```go
ver, err := dev.DRMVersion()
if err != nil {
    log.Fatal(err)
}
fmt.Printf("Driver: %s %s (%s)\n", ver.Name, ver.Version, ver.Date)
```

### amdgpu_top-compatible JSON output

```go
snap := &amdgpu.DeviceSnapshot{
    // ... populate fields ...
}
data, err := amdgpu.MarshalFrameJSON([]*amdgpu.DeviceSnapshot{snap}, 1000, amdgpu.Version)
if err != nil {
    log.Fatal(err)
}
fmt.Println(string(data))
```
